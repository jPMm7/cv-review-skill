# Top 5 Job Positions Matching Guide

Derive the **Top 5 Job Positions** strictly from **verifiable evidence** in the candidate's CV (experience, projects, competitions, coursework, degree, and tools). Never recommend roles solely on generic buzzwords if the CV lacks proof.

---

## Matching Principles

1. **Rank by Realistic Interview Conversion (highest to lowest):**
   - **#1–#2** should reflect the candidate's strongest, rarest intersection of proven skills and hands-on output.
   - **#3–#4** should cover adjacent high-demand roles where core fundamentals and tech stack strongly overlap.
   - **#5** can be a high-ceiling / stretch target **only if** clearly labeled with **Current Fit % vs. Potential Fit %** and the exact gap to close (e.g., *"65% current fit → 85% once 1 AI agent project is added"*).

2. **Avoid Generic Titles:**
   - Instead of vague `"Software Developer"`, specify target role + stack/domain, e.g.:
     - *Simulation / 3D Graphics / Digital Twin Software Engineer (`C++ / Python / WebGL`)*
     - *Junior Full-Stack Software Engineer (`React / TypeScript / PostgreSQL / REST APIs`)*
     - *Computer Vision / ML Engineering Intern (`YOLO / OpenCV / Python`)*
     - *Robotics & Autonomous Systems Intern (`ROS 2 / C++ / Python / Docker`)*
     - *Backend Software Engineer (`.NET / C# / SQL / Azure`)*

3. **Distinguish Claimed vs. Proven Skills:**
   - If the CV lists `AI & Agentic Systems` or `Docker` or `Rust` in `Technical Skills` with **zero supporting bullets** in `Experience` or `Projects`, explicitly cap the **Current Fit %** and tell the user what concrete proof (project, GitHub link, PR) unlocks that role.

---

## Output Format for Each of the Top 5 Positions

For every position, provide:
1. **Exact Role Title & Core Stack** + **Estimated Fit %** (plus `Potential Fit %` if conditional on closing a visible CV gap).
2. **Why it fits (Evidence-backed):** Cite specific internships, projects, GPA, competitions, or coursework directly observed in the CV.
3. **Target Environments / Examples** (e.g., R&D institutes, product startups, robotics/drones, fintech, consulting graduate programs).
4. **1 Concrete Tweaks to Maximize Callbacks** (optional if already 90%+).
